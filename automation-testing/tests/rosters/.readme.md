# 📘 Roster Widget Test Suite (Playwright)

## 🧩 Overview

This project contains an end-to-end (E2E) test suite built with **Playwright** to validate the functionality, usability, and accessibility of the **Roster Widget**.

The test suite ensures that core features such as sorting, filtering, printing, downloading, and accessibility compliance work as expected.

---

## 🚀 Features Covered

* ✅ School selection and roster loading
* 🔃 Sorting (jersey, name, class, position)
* 🎓 Filtering (class and position)
* 🖨️ Print roster functionality
* 📥 Download roster as CSV
* ♿ Accessibility validation (ARIA attributes & labels)

---

## ⚙️ Tech Stack

* **Playwright** – End-to-end testing framework
* **Node.js** – Runtime environment

## 🔧 Setup & Installation

### 1. Install dependencies

```bash
npm install
```

### 2. Install Playwright browsers

```bash
npx playwright install
```

### 3. Configure environment variables

Create a `.env` file in the root directory:

```env
baseUrls=https://your-sandbox-url.com
```

---

## ▶️ Running Tests

Run all tests:

```bash
npx playwright test
```

Run tests in headed mode:

```bash
npx playwright test --headed
```

Run a specific test file:

```bash
npx playwright test tests/roster.spec.js
```

## 🔁 Helper Functions

Key reusable functions:

* `openRosterPage()` → Opens and validates initial page
* `prepareRoster()` → Prepares test state
* `waitForPageReady()` → Ensures page load completion
* `sortByColumn()` → Handles sorting logic
* `openClassFilter()` → Opens class filter
* `openPositionFilter()` → Opens position filter
* `verifyRosterAccessibility()` → Accessibility checks
* `verifyRosterAriaState()` → ARIA validation

---

## 🧠 Best Practices

### ✅ Recommended

* Use reusable helper functions
* Validate UI and accessibility together
* Wait for network idle to avoid flaky tests

### ⚠️ Improvements

* Replace text selectors with `data-testid`
* Avoid hardcoded values (use config/fixtures)
* Clean up downloaded files after tests

---

## 🐞 Troubleshooting

### Tests failing due to timeout

* Increase timeout in `expect()`
* Ensure backend/API is stable

### Element not found

* Verify selector accuracy
* Check if UI has changed

### Download issues

* Ensure browser permissions allow downloads
* Validate `download.path()` is not null
